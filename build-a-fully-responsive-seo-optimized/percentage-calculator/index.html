    Step-by-step explanation

    1. Choose the percentage calculation type.
    2. Use X as the base or starting value.
    3. Use P for a direct percent calculation, or Y for comparison modes.
    4. Apply the selected formula and format the result clearly.

    Formula used

    Percent of X = X x P / 100. Percentage change = (Y - X) / X x 100.

    Example calculation

    15% of 200 is 30. Increasing 200 by 15% gives 230.

    Frequently asked questions

    What is percent change?

    Percent change compares a new value with an old value as a share of the old value.

    Can I calculate discounts?

    Yes. Use decrease X by P% for discount-style calculations.

    Can values be decimal?

    Yes. Decimal values and decimal percentages are supported.
