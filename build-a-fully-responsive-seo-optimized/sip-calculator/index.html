    Step-by-step explanation

    1. Convert the expected annual return to a monthly return.
    2. Calculate the total number of monthly SIP contributions.
    3. Apply the future value formula for payments made at the beginning of each month.
    4. Subtract total invested amount from maturity value to estimate wealth gained.

    Formula used

    FV = P x (((1 + i)^n - 1) / i) x (1 + i), where i is monthly return and n is months.

    Example calculation

    Investing INR 10,000 monthly for 10 years at 12% may grow to about INR 23,23,391, with INR 12,00,000 invested.

    Frequently asked questions

    Is SIP return guaranteed?

    No. SIP returns depend on market performance and the actual fund return.

    Why is the formula different from lump sum investing?

    SIP invests periodically, so each installment compounds for a different amount of time.

    Can I use this for step-up SIPs?

    This calculator uses a constant monthly SIP. For step-up SIPs, use a separate yearly increase model.
