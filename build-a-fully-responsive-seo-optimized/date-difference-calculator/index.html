    Step-by-step explanation

    1. Convert both dates to local calendar dates.
    2. Subtract start from end to get elapsed days.
    3. Add one day when inclusive counting is selected.
    4. Convert total days to weeks and show a calendar-style breakdown.

    Formula used

    Total days = end date - start date. Inclusive mode adds one day.

    Example calculation

    From 2026-05-01 to 2026-05-04 is 3 days, or 4 days when the end date is included.

    Frequently asked questions

    What does include end date mean?

    It counts both the start date and the end date as full calendar days.

    Can the end date be before start date?

    No. The calculator asks you to place the later date as the end date.

    Are times included?

    No. This calculator compares calendar dates only.
