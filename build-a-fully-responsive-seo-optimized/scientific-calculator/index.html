    Step-by-step explanation

    1. Read parentheses and function calls first.
    2. Evaluate powers before multiplication and division.
    3. Evaluate addition and subtraction last.
    4. Use degree or radian conversion for trigonometric functions.

    Formula used

    Expressions are parsed by precedence: parentheses, functions, powers, multiplication/division, then addition/subtraction.

    Example calculation

    sqrt(144) + sin(30) + 2^3 in degree mode equals 20.5.

    Frequently asked questions

    Is the expression evaluated with eval?

    No. The site uses a small parser for supported math functions instead of browser eval.

    Which functions are supported?

    sqrt, abs, ln, log, sin, cos, tan, asin, acos, atan, pi, and e are supported.

    How do powers work?

    Use the caret operator, such as 2^8.
